# UI kit — Blog público

Recriação clicável do site de leitura. Compõe os componentes do design system (`window.RioNegroDesignSystem_2f3caf`).

- **ListingScreen.jsx** — título, card de destaque, grade de ArticleCard, "Carregar mais".
- **ArticleScreen.jsx** — coluna de leitura de 720 px, `.rn-article` (Source Serif 4 18/20 px, 1.7, 68ch). Artigos PDF terminam com caixa "Receber PDF".
- **LeadModal.jsx** — captação: nome, e-mail, celular com máscara, consentimento. Validação em pt-BR. Use um e-mail contendo "erro" para ver o alerta de falha.
- **data.jsx** — artigos de exemplo.

Capas são áreas neutras (`--color-surface-muted`) — não há fotografia no material fornecido.
