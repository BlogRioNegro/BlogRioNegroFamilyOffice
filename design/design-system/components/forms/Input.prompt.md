Campo de texto com label, ajuda e erro embutidos.

```jsx
<Input label="Nome completo" autoComplete="name" />
<Input label="E-mail" type="email" help="Enviaremos o PDF para este endereço." />
<Input label="E-mail" error="Informe um e-mail válido." defaultValue="joao@" />
```

Estados: default, hover (borda #5C5854), foco (anel 2 px + offset 2 px), erro, desabilitado.
