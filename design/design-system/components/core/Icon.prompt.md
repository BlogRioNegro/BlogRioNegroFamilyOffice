Ícone de traço (subconjunto do Lucide, stroke 2) para usar dentro de botões, alertas, badges e ações de tabela.

```jsx
<Icon name="download" size={20} />
<Icon name="trash" label="Excluir" />
```

Nomes: x, check, chevron-left, chevron-right, arrow-right, arrow-left, circle-alert, circle-check, triangle-alert, loader (gira), file-text, align-left, pencil, trash, download, external-link, send, plus, search, eye, rotate-ccw. Herda `currentColor`.
